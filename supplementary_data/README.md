# Supplementary data

Complete versions of the supplementary tables of the article. The supplementary PDF shows
abridged versions of the larger tables; the files here contain every row and column.

| File | Content |
|---|---|
| `Supplementary_Tables_complete.xlsx` | Supplementary Tables S1–S13, one sheet per table |
| `Table_S4_meta_analysis_all_genes.csv` | Random-effects meta-analysis of the 18,209 genes present in at least two cohorts (Supplementary Table S4) |
| `Table_S9_GSEA_by_cohort.csv` | Pre-ranked GSEA results by cohort, 15,844 tests with leading-edge genes (Supplementary Table S9) |

All files are generated by the scripts in `scripts/` (steps 2, 4 and 6).
